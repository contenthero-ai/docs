### `get_project`

<Badge>read</Badge>

Read a project: its title, revision and settings (its canvas size, and for a video project its frame rate, delivery loudness, magnetic main track, linkage and the kinds of track linkage reaches), with a summary of its composition by default or the whole composition with detail 'full'. The summary is each track's id, name, type, whether it is the main track and whether it is muted or hidden, and each clip's id, type, place on the timeline, speed, whether it is disabled, its volume in dB when it is not the default (null when muted) and its fade-in and fade-out seconds when set, and source: a clip plays a file (its assetId, the same id view and get_media take, and the window of the file it plays, in the file's seconds) or code (the project modules it imports). Clips that share an assetId were cut from one recording; a clip's id never says so. For a canvas, the summary is each slide with its layers' ids, types and the start of each text layer's text. A timeline read can be narrowed to a frame window or one track, and a canvas read to one slide; a narrowed full read carries only the modules its clips import and names the rest. A read that names clipIds, moduleNames, sourceAssetId or modulesIndex returns those parts alone: each clip named as its summary line, or whole with its code and the modules it imports with detail 'full'; each module named with its code; modulesIndex, every module's name, how many clips draw it, whether none does, and its size, without code; and with sourceAssetId and atSec, where moments of a recording play on the timeline: every clip and frame each second lands on, none where it was cut out. A read names parts or narrows the whole, not both. A project's read also lists the problems its code, modules and geometry hold, of the whole project or of the parts a read names: code reading what a project module does not provide, the compiler's warnings, modules no clip imports, and a zoom that shows a pinned region's own picture outside the pin. Pass the returned revision as expectedRevision on an edit, so a concurrent change to the same thing is refused rather than overwritten. update_project changes the settings. Requires the editor:read scope.

### `get_transcript`

<Badge>read</Badge>

Addresses the words one of two ways. With projectId it reads the words as the timeline plays them, in timeline order. With mediaId it reads the words of that recording itself, within an optional window of the recording's own seconds, including spans no timeline plays. Pass exactly one. The window is start inclusive and end exclusive. A media read's times are in the recording's own clock, and its words come a page at a time with word granularity. The rest of this describes the project read. Read an EDITOR project's transcript mapped to its timeline clips, so you can do content-aware editing. Returns one segment per transcribable clip in timeline order, each carrying the words spoken within it plus its current state ([disabled] = cut/excluded from the render, [enabled] = kept) and its exact clipId. Use this to read what is said, see which parts are already disabled, then target the exact clipId(s) or source-time ranges with update_timeline (disable_ranges to non-destructively cut, set_disabled to toggle a whole clip). Pass `granularity: 'word'` to also get, per segment: word-level timing with ABSOLUTE timeline frames (so split / range ops are exact), per-word confidence + speaker, the derived silence gaps (for dead-air removal; already inset to the cuttable region so cutting them keeps breathing room), and the non-speech audio events; plus the distinct speaker set at the top level. In word mode each word, silence and audio event is a row of values in the order `fields` names. Segments come a page at a time in timeline order: pass the answer's nextCursor back as cursor for the next page, and limit sets how many a page holds. Scope it with `search` (a phrase to find) or `startMs`/`endMs` (a source-media window, which also clips the returned words) to read only the part that matters. Also returns the project's current `revision` so you can edit right away without a separate get_project: pass it as update_timeline's expectedRevision for a concurrency-safe edit, or omit expectedRevision to just apply to the current state. Returns mediaTranscribed:false when the media has not been transcribed yet. Requires the editor:read scope.

### `create_style_library`

<Badge>write</Badge>

Create a style library on this account, and publish its first version when modules are sent. A style library is shared code, not a CSS style. Its modules come from `modules` sent inline, from `fromProject` (modules of one project, read from its saved state, with imports between them rewritten to the library's own), or both; a name sent by both is refused. A library module may import the sandbox's modules and its own library's modules, never a project module. The name is fixed once created, because the code of every clip that imports the library names it. Publishing runs the same checks as saving a project module: code that does not compile, an import it cannot resolve, or a module that reads something another module does not provide is refused with the reason.
