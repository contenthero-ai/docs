---
title: "Claude Code"
description: "Connect ContentHero to Claude Code over the hosted OAuth MCP server."
---

Claude Code supports remote MCP servers natively over HTTP.

## Add the server

```bash
claude mcp add --transport http contenthero https://mcp.contenthero.ai
```

The first call opens an OAuth consent page in your browser. Sign in with your ContentHero account and approve. No API key needed.

## Verify

```
> use the contenthero mcp to get my balance
```

Claude calls `get_balance` and returns your credit balance. The ContentHero tools appear as `mcp__contenthero__*`.

## Install the plugin (recommended)

The ContentHero plugin brings the skill, which encodes the workflows and our model-specific prompt craft, together with this same connector:

```bash
claude plugin marketplace add contenthero-ai/skills
claude plugin install contenthero@contenthero
```

Installed through the plugin, the tools appear as `mcp__plugin_contenthero_ContentHero__*`. See [Skills](/skills/overview) for what the skill does and [Install the Skill](/skills/install) for every other host.

## Manage

```bash
claude mcp list              # see connected servers
claude mcp remove contenthero
```
