## Uploads and imports

An upload is three calls: `POST /media/uploads` reserves the file and answers an upload target, you send the bytes to it, then `POST /media/uploads/{outputId}/complete` finishes it. A large file uses a multipart session: sign the parts that still need bytes, send them, then complete. An import takes a public https URL instead and runs in the background: poll `GET /status/{id}`.

{/* rest:begin uploads */}

| Method | Path | Scope | Purpose |
| --- | --- | --- | --- |
| `POST` | `/media/uploads` | `library:write` | Begin an upload. Reserves the file in your library and answers an upload target: one URL to PUT the whole file to, or a multipart session. |
| `POST` | `/media/uploads/{outputId}/parts` | `library:write` | Sign the parts of a multipart upload that still need bytes. Idempotent, so a paused upload resumes by asking again. |
| `GET` | `/media/uploads/{outputId}/parts` | `library:write` | List the parts of a multipart upload the store already holds. |
| `POST` | `/media/uploads/{outputId}/complete` | `library:write` | Finish an upload once its bytes are sent. Idempotent: completing twice answers the same media. |
| `DELETE` | `/media/uploads/{outputId}` | `library:write` | Abort an upload that has not completed. A completed upload is refused: delete the media instead. |
| `POST` | `/media/imports` | `library:write` | Import a file from a public https URL as library media. Asynchronous: poll `GET /status/{id}` with the returned id. |

## Favorite, archive and share

One route each, for every kind of item. Archiving is reversible; deleting is a separate call on each resource.

{/* rest:begin marks */}

| Method | Path | Scope | Purpose |
| --- | --- | --- | --- |
| `POST` | `/favorite` | `favorites:write` | Favorite or unfavorite any asset: a media item by `mediaId`, anything else by `assetType` and `id`. |
| `POST` | `/archive` | `favorites:write` | Archive or restore any asset. Reversible; deleting is a separate call on each resource. |
| `POST` | `/share` | `studio:write` and `editor:write` | Make an item's public link, or stop sharing it. One route for every shareable kind. |
