The identity layer: avatars with their looks, and the voices they speak with. 7 tools.

Every tool below is exposed by the hosted MCP server at `https://mcp.contenthero.ai` and by the `@contenthero/mcp` npm package. A <Badge>write</Badge> tool changes your account; a <Badge>read</Badge> tool does not.

### `list_avatars`

<Badge>read</Badge>

List the account's avatars. Each avatar has an imageUrl (its base look) and a defaultVoiceId, which feed generate_lip_sync. Call get_avatar for full detail and the avatar's looks.

Takes no parameters.

### `get_avatar`

<Badge>read</Badge>

Get one avatar by id: its base image (use as generate_lip_sync imageUrl), default voice, traits, and its looks (outfit variations).

<ParamField body name="avatarId" type="string" required>
The avatar id from list_avatars.
</ParamField>

### `create_avatar`

<Badge>write</Badge>

Create a reusable character and start generating its first look. SPENDS CREDITS (pass getCost to preview the price without creating anything). Returns as soon as the record exists: the avatar is NOT usable yet, it sits at status 'processing' with no image until its first look finishes, so poll get_avatar until status is 'completed'. Supply referenceImageUrls to make the avatar a likeness of a real person from their photos; omit them to invent a character from the description and traits.

<ParamField body name="age" type="string" required>
Apparent age, e.g. '20s', '35', 'middle-aged'. Required: the prompt writer describes the character from these traits.
</ParamField>

<ParamField body name="gender" type="string" required>
Gender presentation. Required, same reason as age.
</ParamField>

<ParamField body name="name" type="string" required>
Avatar name, at least 3 characters.
</ParamField>

<ParamField body name="defaultVoiceId" type="string">
A voiceId from list_voices, used as this avatar's default voice.
</ParamField>

<ParamField body name="description" type="string">
Free-text description of the character. The strongest single input when no reference photos are given.
</ParamField>

<ParamField body name="ethnicity" type="string">
Optional ethnicity, for a more specific likeness.
</ParamField>

<ParamField body name="getCost" type="boolean">
Return the credit cost estimate instead of creating (nothing runs, nothing is charged).
</ParamField>

<ParamField body name="niche" type="string[]">
Content niches this character is for, e.g. ["fitness","nutrition"].
</ParamField>

<ParamField body name="referenceImageUrls" type="string[]">
Photos of a REAL PERSON to anchor identity to: each a URL or a previous output id. Only use photos of someone who has agreed to being cloned.
</ParamField>

<ParamField body name="style" type="string">
Visual style hint for the portrait, e.g. "editorial", "cinematic". Not stored on the avatar.
</ParamField>

### `update_avatar`

<Badge>write</Badge>

Update an avatar and/or change its looks. Fields: name, defaultLookId (also becomes the avatar's profile photo), defaultVoiceId. Looks are changed through ops, the same shape update_timeline and update_canvas use: add_look files images the account ALREADY OWNS onto the avatar, remove_look trashes one (recoverable for 30 days). Ops run before the fields, so one call can add a look and make it the default. To GENERATE a new look instead of filing an existing image, call generate_image with avatarId.

<ParamField body name="avatarId" type="string" required>
The avatar id from list_avatars.
</ParamField>

<ParamField body name="defaultLookId" type="string">
A look id from get_avatar. Becomes the avatar's default look AND its profile photo.
</ParamField>

<ParamField body name="defaultVoiceId" type="string,null">
A voiceId from list_voices, or null to clear it.
</ParamField>

<ParamField body name="name" type="string">
New name, at least 3 characters.
</ParamField>

<ParamField body name="ops" type="value[]">
Look changes, applied in order before the field updates. NOT a transaction: a failure part-way leaves earlier ops applied.
</ParamField>

### `delete_avatar`

<Badge>write</Badge>

Delete an avatar. Soft: the avatar stops appearing, but ITS LOOKS SURVIVE as library images and can be filed onto another avatar with update_avatar's add_look. Use this to retire a duplicate or an abandoned character, after moving any looks worth keeping.

<ParamField body name="avatarId" type="string" required>
The avatar id from list_avatars.
</ParamField>

### `list_voices`

<Badge>read</Badge>

List the account's saved voices (favorites first). Set favorited=true to show only favorites. Each has a voiceId for generate_lip_sync / generate_audio (TTS). Call get_voice for full detail.

<ParamField body name="favorited" type="boolean">
Only favorited voices.
</ParamField>

### `get_voice`

<Badge>read</Badge>

Get one voice by its voiceId: provider, traits (accent/language/gender/age), description, and a preview URL.

<ParamField body name="voiceId" type="string" required>
The voice id from list_voices.
</ParamField>
