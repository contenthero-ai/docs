Base URL `https://app.contenthero.ai/api/v1`. All endpoints take a bearer API key. The tables on this page are generated from the route contract: the Scope column is the scope the key needs, and a route that lists two scopes needs both.

## Projects

A project is an editor timeline or a canvas. `GET /projects/{projectId}` answers its composition `state` and its `revision`; pass the revision back as `expectedRevision` when you edit, so a write over a newer edit is refused instead of overwriting it. Project settings (canvas size, frame rate, loudness, linkage) change through `PATCH /projects/{projectId}`, never through the edit path.

{/* rest:begin projects */}

| Method | Path | Scope | Purpose |
| --- | --- | --- | --- |
| `GET` | `/projects` | `editor:read` | List your editor and canvas projects, filtered and sorted, a page at a time. |
| `POST` | `/projects` | `editor:write` and `planner:write` | Create an editor or canvas project, and a card for it. |
| `POST` | `/projects/import` | `editor:write` and `planner:write` | Import a PowerPoint or Google Slides file (by URL) or a Canva design (by id) into a new canvas project with editable layers. |
| `GET` | `/projects/{projectId}` | `editor:read` | One project in full: metadata, composition `state`, `revision` and `type`. Pass `revision` back as `expectedRevision` when editing. |
| `PATCH` | `/projects/{projectId}` | `editor:write` | Change a project's name, brand kit, cover and settings (canvas size, fps, loudness, linkage). Settings change through the edit path, so they are undoable and versioned. |
| `DELETE` | `/projects/{projectId}` | `editor:write` | Permanently delete a project. Irreversible, so it needs `confirm=true`; archive is the reversible alternative. |
| `POST` | `/projects/{projectId}/duplicate` | `editor:write` | Copy a project, optionally from one of its saved versions (`versionId`, a premium feature). |
| `POST` | `/projects/{projectId}/undo` | `editor:write` | Reverse the project's most recent edit, or the one named by `revision`. Answers the new revision. |
| `POST` | `/projects/{projectId}/redo` | `editor:write` | Re-apply the edit most recently undone. Answers the new revision. |

## Exports

An export renders the project's saved composition in the background: start it, then poll `GET /exports/{exportId}` or `GET /status/{id}` until it finishes, then fetch the file with `GET /download/{id}`.

{/* rest:begin exports */}

| Method | Path | Scope | Purpose |
| --- | --- | --- | --- |
| `GET` | `/export-formats` | `editor:read` | The export formats and their options, by project kind: what `POST /projects/{projectId}/export` accepts. |
| `POST` | `/projects/{projectId}/export` | `editor:write` | Start an export (a render) of the project's saved composition. Asynchronous: answers `{ exportId, status }`. |
| `GET` | `/projects/{projectId}/exports` | `editor:read` | The project's exports, newest first, finished and running, a page at a time. |
| `GET` | `/exports/{exportId}` | `editor:read` | Poll one export: its status, progress and, once finished, its output URL. |

## Edits and schemas

`POST /editor/ops` applies a batch of ops to a project and saves it atomically. The schema routes list what an op, a layer, a clip, a track and an effect can be, so a call can be built from the real shapes.

{/* rest:begin editor */}

| Method | Path | Scope | Purpose |
| --- | --- | --- | --- |
| `POST` | `/editor/ops` | `editor:write` | Apply a batch of ops to a project's composition (canvas slides or editor timeline) and save atomically, with optimistic concurrency and an op log. |
| `GET` | `/editor/transcript` | `editor:read` | A project's transcript mapped to timeline clips, in timeline order, so edits can target exact clip ids. |
| `GET` | `/editor/layer-types` | `editor:read` | The canvas schema: every `update_canvas` op and layer type with its shape. With `name`, one entry in full. |
| `GET` | `/editor/timeline-types` | `editor:read` | The editor timeline schema: every `update_timeline` op, clip type and track type. With `name`, one entry in full. |
| `GET` | `/editor/effects` | `editor:read` | Every effect a clip can carry, with its group and what it does. With `name`, one effect and its parameters in full. |
| `GET` | `/editor/code-guide` | `editor:read` | The authoring guide for a clip's code: what the sandbox provides, the composition's units, the brand props and the size limit. |
