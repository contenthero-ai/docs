Commands follow `contenthero <noun> <verb>`. Run `contenthero --help` for the live tree, `contenthero <command> --help` for one command's flags, and `contenthero schema` to dump the input schema of every command.

## Discover

```bash
contenthero --help                 # the full command tree
contenthero generate image --help  # one command's flags
contenthero schema                 # JSON Schema of every command's inputs
```

`contenthero schema` is the discovery tool for agents: it returns the argument shape of every command without reading the docs.

## Generate

```bash
contenthero generate image     --prompt "..." --model nano-banana-2
contenthero generate image     --prompt "..." --model nano-banana-2 --avatar <avatarId>  # file as a look
contenthero generate video     --prompt "..." --model kling-3.0
contenthero generate audio     --text "..."  --voice <voiceId>
contenthero generate board     --image <url> --type <boardType>
contenthero generate lip-sync  --image <url> --audio <url|outputId>
contenthero upscale            --image <url>
contenthero transcribe         --media <url>
contenthero model list         # the live roster
```

## Generations

```bash
contenthero generation status <outputId>              # blocks until done
contenthero generation status <outputId> --no-wait    # snapshot
```

## Cards (pipeline)

A **card** is one piece of work. Its **posts** are how it reaches each platform, one per platform. Cards live on a **space**, whose columns are **stages**.

```bash
contenthero card list --space <spaceId>
contenthero card get <cardId>
contenthero card create "<title>" --platform instagram --space <spaceId>
contenthero card update <cardId> --stage <id|slug|name>
contenthero card update <cardId> --posts '[{"platform":"instagram","format":"reel","connectedAccountId":"..."}]'
contenthero card update <cardId> --assets '[{"assetUrl":"<mediaUrl>"}]'
contenthero card update <cardId> --schedule <iso8601>
contenthero card publish <cardId>
contenthero archive card <cardId>
```

<Warning>
`--posts` and `--assets` **replace** the whole set. Send every entry you want to keep, not just the new one.
</Warning>

## Spaces and stages

```bash
contenthero space list
contenthero stage list --space <spaceId>
contenthero stage create "<name>" --space <spaceId> --after <stageId>
contenthero stage update <stageId> --space <spaceId> --name "<name>"
contenthero stage delete <stageId> --space <spaceId> --target <stageId>
```

`stage delete` needs `--target` unless the column is empty: the server refuses to silently drop the cards in it.

## Avatars and voices

```bash
contenthero avatar list
contenthero avatar get    <avatarId>
contenthero avatar create "<name>" --age 20s --gender female   # spends credits; --cost to preview
contenthero avatar update <avatarId> --name "..." --default-look <lookId>
contenthero avatar delete <avatarId>                            # soft; its looks survive
contenthero avatar look add    <avatarId> --image <url>         # files an image you already own
contenthero avatar look remove <avatarId> <lookId>              # trashed, recoverable 30 days
contenthero voice list
contenthero voice get <voiceId>
```

`avatar create` returns before the avatar is usable: poll `avatar get` until the status is `completed`. Use `--voice none` on `avatar update` to clear the default voice. Voices are read-only; creating one stays in the app.

## Inspiration

Tracked accounts come in two kinds in one list: `inspiration` for creators you watch, `brand` for your own profiles. `content list` spans both and ranks by outlier score.

```bash
contenthero tracked-account list [--kind inspiration|brand] [--brand-kit <id>]
contenthero tracked-account get <accountId>
contenthero content list [--brand-kit <id>] [--scope <scope>] [--since week]
contenthero content get <contentId> --transcript text
```
