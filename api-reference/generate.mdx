Base URL `https://app.contenthero.ai/api/v1`. All endpoints take a bearer API key. The tables on this page are generated from the route contract: the Scope column is the scope the key needs (`None` means any valid key), and the fields under a route are its query, body and, where declared, its answer.

## Generation

`POST /studio/generate` takes a `contentType` (`image`, `video` or `audio`) and a `modelId`; the model registry decides which other fields apply. It smart-waits, then answers the asset or an `outputId` to poll. Pass `getCost: true` to preview the cost only. A long post transcription answers `202` with `status: "running"`: ask again with the same post to follow it, free.

A generation reference (start frame, image input, audio) accepts a raw URL or a ContentHero output-id token `<uuid>-<N>`.

| Method | Path | Scope | Purpose |
| --- | --- | --- | --- |
| `POST` | `/studio/generate` | `studio:generate` | Generate an image, a video or audio (speech, music, sound effects), or run an upscale, background removal, layer separation or lip-sync. `contentType` picks the family and the model registry entry for `modelId` decides what else is accepted. Waits for a short job and answers a pending `outputId` for a long one. |
| `GET` | `/studio/generate/{outputId}` | `studio:generate` | Poll one generation by its `outputId`: its status, and its files once it has finished. Reading never starts or finishes work. |
| `POST` | `/studio/reference-sheet` | `studio:generate` | Generate a reference sheet: a typed panel layout drawn from a source image. |
| `POST` | `/studio/audio/edit` | `studio:generate` | Edit existing audio: isolate a voice, enhance speech or split stems. The registry names the model that performs the operation. |
| `POST` | `/studio/transcribe` | `studio:generate` | Transcribe speech to text from an audio file (`audioUrl`), a public video page (`videoUrl`) or a tracked post (`contentId`). Not free: pass `getCost` first to price it. |

## Media

`GET /download/{id}` answers `404` when the id names nothing of yours and `409` when the file is not made yet. Each link it returns is a save link that names the file, needs no sign-in and does not expire. It never spends.

| Method | Path | Scope | Purpose |
| --- | --- | --- | --- |
| `GET` | `/media` | None | List the files in your library, or the stock catalog with `source=stock`, a page at a time. |
| `GET` | `/media/{token}` | None | One media item in detail, by its short id or full id (a generation adds `-N` for one variation). |
| `PATCH` | `/media/{token}` | `library:write` | Rename or describe a stored file you own. A generated output or a stock item has nothing to set and is refused. |
| `GET` | `/media/search` | None | Semantic search over your library (creations, uploads, licensed stock, brand assets), ranked, with matched scene timestamps. |
| `POST` | `/media/batch` | None | Resolve a mixed batch of media references (URLs or media ids) to vision-ready URLs and light metadata. |
| `GET` | `/download/{id}` | None | Save links for a file of yours or a project export, by media id or export id: `{ files: [{ mediaId?, name, url }] }`. |
